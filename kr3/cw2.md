# Техническое задание

## Контрольная работа по JavaScript

**Вариант 1:** «Игровая карточка игрока»  
**Максимальный балл:** 20  
**Технологии:** HTML, CSS, JavaScript

## 1. Цель работы

Разработать интерактивную страницу, которая по нажатию кнопки формирует игровую карточку из имени игрока и введённого количества очков. Закрепить навыки работы с DOM, событиями, строками, числами, проверками, условными конструкциями и шаблонными строками.

## 2. Исходные файлы

Используется готовый файл `index.html` из задания. Нужно создать файл `main.js` в той же папке. Логика приложения должна находиться в `main.js`.

Элементы HTML:

| ID            | Назначение                              |
| ------------- | --------------------------------------- |
| `title`       | Заголовок страницы                      |
| `nameInput`   | Поле имени и фамилии                    |
| `numberInput` | Поле количества очков                   |
| `btn`         | Кнопка «Создать карточку»               |
| `result`      | Блок результата или сообщения об ошибке |

В заготовке предусмотрены классы оформления `legend`, `pro`, `newbie` и `error`.

## 3. Функциональные требования и оценивание

### Шаг 1. Получение данных — 2 балла

- Найти необходимые элементы страницы через JavaScript.
- Записать в `#title` заголовок «Игровая карточка игрока».
- Назначить обработчик `click` на `#btn`.
- При нажатии получить значения полей.
- Удалить пробелы в начале и конце имени с помощью `trim()`.

### Шаг 2. Проверка имени — 2 балла

Если после удаления пробелов имя пустое, вывести в `#result` точный текст **«Введите название»**, присвоить блоку класс `error` и прекратить обработку.

### Шаг 3. Форматирование имени — 2 балла

- Удалить лишние пробелы между словами, оставив один.
- Каждое слово привести к виду: первая буква заглавная, остальные строчные.

Примеры:

| Ввод                   | Ожидаемый результат |
| ---------------------- | ------------------- |
| `ИВАН ПЕТРОВ`          | `Иван Петров`       |
| `алексей морозов`      | `Алексей Морозов`   |
| `  мАРИЯ   сМИРНОВА  ` | `Мария Смирнова`    |

Можно использовать `split()`, `map()`, `slice()`, `toUpperCase()`, `toLowerCase()`, `join()`.

### Шаг 4. Аббревиатура и длина — 2 балла

- Сформировать аббревиатуру из первых букв слов, заглавными буквами.
- Посчитать количество символов имени без пробелов.

Пример: `Алексей Морозов` → аббревиатура `АМ`, длина `14`.

### Шаг 5. Запрещённое слово — 2 балла

Проверить, содержит ли имя отдельное слово `test` в любом регистре. При обнаружении вывести **«Такое название нельзя»**, применить класс `error` и прекратить создание карточки.

| Ввод             | Результат |
| ---------------- | --------- |
| `Ivan TEST`      | Ошибка    |
| `test player`    | Ошибка    |
| `TeSt`           | Ошибка    |
| `Contest Player` | Допустимо |

### Шаг 6. Проверка очков — 2 балла

- Преобразовать значение `#numberInput` в число с помощью `Number()`.
- Проверить, что поле не пустое и результат — конечное число.
- Если значение некорректно, вывести точный текст **«Введите цену»** и применить класс `error`.
- Дробное число с точкой, например `87.456`, должно приниматься.

**Примечание:** формулировки ошибок сохранены из исходного задания, хотя в игровом варианте числовое поле означает очки.

### Шаг 7. Промокод и округление — 2 балла

- Сгенерировать случайное целое число от **10 до 99 включительно** (промокод).
- Представить очки с двумя цифрами после десятичной точки через `toFixed(2)`.

Пример: `87.456` → `87.46`.

### Шаг 8. Категория игрока — 2 балла

Определить категорию по исходному числу очков, **до округления**, используя `if / else if / else`.

| Очки                | Текст        | CSS-класс |
| ------------------- | ------------ | --------- |
| `>= 1000`           | `Скидка 10%` | `legend`  |
| `>= 500` и `< 1000` | `Скидка 5%`  | `pro`     |
| `< 500`             | `Без скидки` | `newbie`  |

Класс применяется к `#result`. При повторном расчёте предыдущий класс результата следует заменять, а не накапливать.

### Шаг 9. Вывод карточки — 2 балла

Сформировать HTML-разметку **шаблонной строкой JavaScript** (обратные кавычки и `${...}`). Вывести в `#result`:

1. Отформатированное имя и фамилию игрока.
2. Аббревиатуру.
3. Длину имени без пробелов.
4. Очки с двумя знаками после точки.
5. Случайный промокод.
6. Текст категории.

Новая карточка **заменяет** старую. Для безопасного вывода пользовательского текста необходимо исключить интерпретацию введённого имени как HTML-разметки, например экранировать специальные символы перед вставкой в шаблонную строку.

### Шаг 10. Качество кода — 2 балла

- Понятные имена переменных.
- Читаемое форматирование и отступы.
- Отсутствие ненужного повторения кода.
- Корректное прекращение обработки при ошибках.
- Отсутствие ошибок в консоли браузера.

## 4. Пример результата

**Ввод:**

- Имя: `Алексей Морозов`
- Очки: `1250.567`

**Пример карточки:**

```text
Карточка игрока

Очки: 1250.57

```

Промокод `42` приведён для примера и при каждом создании генерируется случайно. Для такой карточки блок `#result` должен иметь класс `legend`.
