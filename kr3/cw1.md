### Вариант 1. «Игровая карточка игрока» (20 баллов)

## По клику на кнопку страница собирает игровую карточку в #result. В поле имени вводят имя игрока, в поле числа — его очки (дробные, например 87.456).

|  Шаг   | Что нужно сделать                                                                                            |
| :----: | :----------------------------------------------------------------------------------------------------------- |
| **1**  | Найти элементы, повесить обработчик, взять название и убрать лишние пробелы                                  |
| **2**  | Если название пустое, показать «Введите название» с классом `error`                                          |
| **3**  | Название с большой буквы, остальное маленькими для каждого слова                                             |
| **4**  | Аббревиатура из первых букв слов («СМ») и длина названия без пробелов                                        |
| **5**  | Проверить: если в названии есть слово «test» (в любом регистре), показать «Такое название нельзя»            |
| **6**  | Превратить цену в число; если не число — «Введите цену»                                                      |
| **7**  | Случайный промокод — число от 10 до 99; цена округлена до двух знаков (`toFixed(2)`)                         |
| **8**  | Скидка: от 1000 — «Скидка 10%» (класс `legend`), от 500 — «Скидка 5%» (`pro`), иначе «Без скидки» (`newbie`) |
| **9**  | Вывести карточку через шаблонную строку                                                                      |
| **10** | Чистый код                                                                                                   |
